# 自动剧情（autostory）

任务标识 `AutoStory`，配置键 `auto_story`，位于“游戏辅助”（`gamehelper`）分类。仅保留调度配置，默认关闭。

启动时识别到 `story_back`，或庭院 `main` 且有 `chat1` 时执行，否则跳过。庭院沿用全局皮肤替换并排除设置界面；在庭院有 `chat1` 时点击，后续独立识别并点击对话跳过。只有回到庭院且没有 `chat1`、对话跳过或待关闭弹窗，或识别到 `page_heian_hyakumonogatali` 页面时才结束。

任务循环识别，不维护事件状态或等待事件结束：

- fight、两个 chat、阴阳师之眼入口，只在当前截图识别到 `story_back` 时点击。
- 对话 `story_chat_skip`、视频 `skip_confirm` 和 `skip` 全局独立识别，出现就点，不要求 `story_back`；视频确认优先于跳过，两个独立判断。
- 视频没有跳过入口但存在 `story_video_speed` 时走第二种视频处理：复用 `ui_click_until_disappear` 点击加速直到变为 `story_video_speed_done`；随后用 `wait_until_disappear` 等 `done` 消失，再用 `wait_until_appear` 最多等 10 秒回 `story_back`，超时交回主循环（例如直接进入战斗准备页）。跳过入口一旦可见仍优先走第一种处理。
- 视频后全局检测通用准备页，出现则接管战斗；返回 `story_back` 后继续剧情循环。
- fight 点击后复用通用战斗；仅确认、准备，不切换阵容、御魂或增益，其余使用通用战斗及结算资源。
- 入口按钮（fight、chat1、chat2、阴阳师之眼、视频 skip）点击间隔 2 秒；后续对话跳过、视频确认、战斗确认与准备间隔 0.4 秒，视频加速间隔 1 秒，外层循环等待 0.4 秒。
- 剧情主页面无可处理操作超过 5 秒，随机向左或向右走，此后每隔随机 2–4 秒走一步；处理剧情操作后重置等待。
- 未知界面复用共享随机点击，第一下立即执行，后续每隔随机 2–4 秒执行，与左右走的频率一致；随机点击后的下一帧补一次 `shikigami_story_skip` 检测，出现则点击；不以 `story_back` 消失作为任务结束条件。
- 全局识别 `new_onmyoji_red_close` 并点击关闭，刷新截图后继续。
- 每轮剧情处理前清空点击历史，避免持续执行入口与跳过触发重复点击上限；通用战斗内保留原有保护。
- 识别到 `loading_1` 或 `loading_2` 时只刷新等待，加载消失后继续，覆盖入口和战斗期间。
- 点击 fight 后最多等待 3 秒识别准备页，成功后才接入通用战斗；未进入则返回外层重新识别当前页面。

入口跳过按失败间隔调度，识别庭院结束后按成功间隔调度。
